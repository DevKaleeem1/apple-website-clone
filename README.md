This project is a frontend clone of the Apple official website, created using pure HTML and CSS.
The goal of this project is to practice modern web layout techniques and improve UI design skills.

🚀 Features

Clean and modern Apple-style UI

Fully responsive layout

Built using only HTML & CSS (no JavaScript)

Flexbox & CSS positioning used for layout

Pixel‑inspired design similar to the original Apple website

🛠 Technologies Used

HTML5

CSS3

📌 Purpose

This project is made for learning and practice purposes only.
